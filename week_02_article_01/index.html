2F 모델 조립 라인

모델이라는 기계를 뜯어 본다 — 토큰 하나가 층을 지나 다음 토큰이 되기까지

인턴 시아 · 공정 안내

여기는 2F 모델 조립 라인이에요. 토큰 하나가 층을 지나 다음 토큰이 되기까지. 이 해설은 이 층의 기계 2대를 맡았어요. 번호를 누르면 그 칸으로 내려갑니다.

    그래서 이 편에서 돌리는 다이얼은?

    오늘날 LLM의 출발점입니다. KV 캐시와 계산 방식, 두 다이얼이 바로 이 구조에서 나와요.

    1. ① 목표 정하기빨리(지연시간) · 많이(처리량) · 싸게(비용) 중 무엇을 먼저 지킬까
    2. ② 모델 성질 보기질문 읽기(프리필)는 계산이 막히고, 한 토큰씩 쓰기(디코드)는 메모리 통로가 막힌다
    3. ③ 기계 맞추기모델이 VRAM에 들어가나, 메모리 대역폭은 충분한가
    4. ④ 다이얼 돌리기아래 다섯 다이얼을 목표에 맞춰 조절한다
    5. ⑤ 재고 병목 찾기계기판(TTFT · TPS · P99)과 루프라인으로 막힌 곳을 찾고 → 다시 ②로
    • 배치한 번에 몇 주문을 함께 돌릴까 — 많이 묶을수록 처리량은 오르고, 주문 하나의 기다림은 길어질 수 있다
    • 정밀도숫자를 몇 자리로 담을까 (양자화) — 작게 담으면 메모리와 속도에서 이득, 품질은 다시 재 봐야 한다
    • KV 캐시이 편어텐션의 키 · 값이 바로 KV 캐시에 쌓이는 메모입니다.
    • 나눠 싣기모델과 공정을 GPU 여러 대에 어떻게 나눌까 (병렬화 · 분리) — 한 대에 안 들어가거나 더 빨라야 할 때 쓴다
    • 계산 방식이 편어텐션 계산은 문장이 길수록 크게 늘어서, 계산 방식 다이얼의 주된 대상이 됩니다.

    불이 켜진 단계와 다이얼이 이 편이 맡은 자리입니다. 회색은 다른 편에서 다룹니다.

    눈금 맞춘 형광펜논문 이름: Scaled Dot-Product Attention

    질문과 색인표를 맞대 점수를 내고, 점수가 너무 커지지 않게 눈금을 맞춘 뒤 내용을 섞는다.

    여러 색 형광펜논문 이름: Multi-Head Attention

    형광펜 8자루가 각자 다른 관계를 동시에 표시한다.

    질문 카드·색인표·내용논문 이름: Query · Key · Value

    무엇을 찾는지, 각 단어의 꼬리표, 실제로 가져올 정보.

    자리 물결표논문 이름: Positional Encoding

    단어마다 "몇 번째 자리"를 사인·코사인 물결로 붙인다.

    앞만 보기 가림막논문 이름: Masking (디코더)

    번역문을 쓸 때 아직 안 쓴 뒤쪽 단어를 못 보게 가린다.

    읽는 탑 · 쓰는 탑논문 이름: Encoder · Decoder

    원문을 읽어 표현으로 바꾸는 쪽과, 번역문을 한 단어씩 쓰는 쪽.

    지름길 + 층 정규화논문 이름: Residual connection + LayerNorm

    각 단계의 입력을 출력에 그대로 더하고 크기를 고른다.

    단어별 작은 신경망논문 이름: Position-wise Feed-Forward Network

    어텐션 뒤에 단어마다 따로, 같은 작은 신경망을 한 번 통과시킨다.

    번역 채점표논문 이름: BLEU

    기계 번역이 사람 번역과 단어 조각을 얼마나 겹치게 썼는지 재는 점수.

    기존 생각과 이 논문

    논문: 1장 서론 · 2장 배경

    기존 생각

    순서대로 읽어야 문장을 안다. 순환 신경망(RNN, LSTM)은 단어를 하나씩 읽으며 기억 상자 hₜ를 고쳐 쓴다. hₜ는 hₜ₋₁이 끝나야 계산되므로 한 문장 안에서는 나눠 계산(병렬화)할 수 없다. 어텐션은 이미 쓰였지만 대부분 순환 신경망에 덧붙인 보조 장치였다.

    →
    이 논문

    순환을 빼고 어텐션만 쓴다. 모든 단어가 다른 모든 단어를 한 번에 참고한다. 먼 단어 사이 경로가 한 걸음이 되고, 문장 안 계산을 한꺼번에 돌릴 수 있다. 논문은 이것을 "어텐션에만 기댄 첫 번째 번역(변환) 모델"이라고 불렀다.

    초파리 연구원

    합성곱도 병렬로 돌잖아. 굳이 어텐션이어야 해?

    논문의 답은 "먼 단어 사이 거리"입니다. 합성곱은 두 단어를 잇는 데 필요한 연산 수가 거리에 따라 늘고(ConvS2S는 선형, ByteNet은 로그), 셀프 어텐션은 거리와 상관없이 상수입니다. 6번 섹션에서 직접 늘려 봅니다.

    번역 한 번이 지나가는 길

    모델: 인코더 6층 + 디코더 6층논문: 그림 1, 3장

    실무에서 비슷한 작업

    문서 분류, 고객 문의 요약, 설비 로그 이상 탐지처럼 "순서가 있는 기록"을 다루는 일에 오늘날 거의 같은 블록이 쓰입니다. 읽는 탑만 쓰면 분류·검색용, 쓰는 탑만 쓰면 문장 생성용이 됩니다.

    비유의 한계: 논문은 번역과 구문 분석만 실험했어요. 다른 업무에서의 성능은 이 논문이 보여 준 것이 아닙니다.

    3결과 1

    눈금 맞춘 형광펜 — 질문·색인표·내용

    모델: softmax(QKᵀ/√dₖ)V일상: 형광펜 긋고 필요한 줄만 다시 보기논문: 식 (1), 3.2.1절

    일상으로 치면

    시험 공부를 하다 "its가 뭐였지?" 하는 질문이 생기면, 교과서에서 그 질문과 잘 맞는 줄에 진하게, 덜 맞는 줄에 옅게 형광펜을 긋고, 진한 줄 위주로 다시 읽는다.

    모델에서는

    단어마다 질의(질문 카드), 키(색인표), 값(내용)을 만든다. 질의와 각 키의 내적을 √dₖ로 나누고 소프트맥스로 합이 1인 가중치로 바꾼 뒤, 값을 가중 평균한다.

    행동으로 보기 — 질문 단어를 고르면 형광펜이 그어진다

    질문 단어

    √dₖ 눈금 실험 — 나누지 않으면 무슨 일이?

    dₖ64

    한 걸음씩

    1. 질문 단어의 질의 벡터 q와 모든 단어의 키 kⱼ를 곱해 더한다(내적). 잘 맞을수록 큰 수.
    2. 그 수를 √dₖ로 나눈다. dₖ가 64면 8로 나눈다.
    3. 소프트맥스로 0~1 사이, 합이 1인 가중치로 바꾼다. 이것이 형광펜 진하기.
    4. 가중치대로 값 벡터를 섞은 것이 그 단어의 새 표현이다.

    이 칸의 한계: 형광펜이 한 자루뿐이면 여러 관계(누가, 무엇을, 어디서)를 한 번에 평균 내 버린다. 다음 칸에서 여러 색을 쓴다.

    수식으로 보기 — 왜 √dₖ인가 (논문 각주 4)

    q와 k의 각 성분이 평균 0, 분산 1인 독립 확률변수라면 q·k = Σᵢ qᵢkᵢ 의 평균은 0, 분산은 dₖ다. dₖ가 크면 내적의 크기가 커져 소프트맥스가 한 곳에 거의 1을 몰아주고, 그 영역에서는 기울기가 매우 작다. 그래서 1/√dₖ를 곱해 분산을 1로 되돌린다.

    소프트맥스 출력 pᵢ의 자기 자신에 대한 기울기는 pᵢ(1−pᵢ)다. 위 실험의 "기울기 크기"는 Σᵢ pᵢ(1−pᵢ)로 잰 값이다(설명용 지표).

    논문은 더하기 어텐션(additive)과 비교해, 이론 복잡도는 비슷하지만 내적 어텐션이 행렬 곱셈으로 구현돼 훨씬 빠르고 메모리를 덜 쓴다고 적었다.

    하루 (조수)

    dₖ를 512까지 올리고 나누기를 꺼 보세요. 가장 큰 가중치가 거의 1이 되고 기울기 크기가 바닥으로 떨어져요.

    4결과 2

    여러 색 형광펜 — 머리를 몇 개 둘까

    모델: Concat(head₁…headₕ)Wᴼ일상: 문법·뜻·지칭을 색 다른 형광펜으로논문: 3.2.2절, 표 3 (A)

    일상으로 치면

    노란 펜은 "누가 무엇을 가리키나", 초록 펜은 "바로 옆 단어", 분홍 펜은 "같은 구절 안"처럼 색마다 다른 관계를 긋는다. 한 자루로 다 그으면 뒤섞여 무엇을 표시했는지 흐려진다.

    모델에서는

    질의·키·값을 h번 서로 다른 학습된 사영으로 dₖ = dmodel/h 차원으로 줄인 뒤 여러 머리가 동시에 어텐션을 계산하고, 결과를 이어 붙여 다시 사영한다. 논문은 h = 8, dₖ = dᵥ = 64를 썼다.

    행동으로 보기 — 펜 색을 켜고 끄기 예시값

    질문 단어

    논문 수치 — 계산량을 같게 두고 머리 수만 바꾸면 논문 수치 · 표 3 (A)

    표 3 (A) 읽는 법

    1. 머리 수 h를 늘리면 머리 하나의 dₖ를 줄여 전체 계산량을 맞췄다 (1×512, 4×128, 8×64, 16×32, 32×16).
    2. 머리 하나(h=1)는 가장 좋은 설정보다 BLEU가 0.9 낮았다 (24.9 vs 25.8).
    3. 머리를 너무 많이(32) 둬도 다시 떨어졌다 (25.4).
    4. 이 표는 영→독 개발 세트(newstest2013), 체크포인트 평균 없이 잰 값이라 표 2의 시험 점수와 직접 비교하지 않는다.

    이 칸의 한계: 형광펜은 단어 "사이"의 관계만 본다. 단어 "자리"는 모른다. 순서를 섞어도 형광펜 결과는 같다. 다음 칸에서 자리를 붙인다.

    수식으로 보기

    MultiHead(Q,K,V) = Concat(head₁,…,headₕ)Wᴼ, headᵢ = Attention(QWᵢQ, KWᵢK, VWᵢV)

    WᵢQ, WᵢK ∈ ℝd_model×dₖ, WᵢV ∈ ℝd_model×dᵥ, Wᴼ ∈ ℝhdᵥ×d_model. 머리마다 차원을 줄였으므로 전체 계산 비용은 차원을 다 쓴 머리 하나와 비슷하다.

    논문은 부록 그림 3~5에서 몇몇 머리가 먼 의존 관계("making … more difficult"), 지칭 해소("its" → "Law"), 문장 구조와 관련된 행동을 "보이는 것 같다"고 해석했다. 위 예시 머리는 그 해석을 흉내 낸 설명용 값이다.

    주판봇

    펜이 하나면 수익이 0.9 깎인다는 거지. 근데 32자루로 늘리면 또 손해. 분산 투자도 적당히야.

    5결과 3

    자리 물결표 — 순서를 잃지 않는 법

    모델: PE(pos,2i)=sin(pos/10000^(2i/d))일상: 줄마다 다른 박자의 물결 도장논문: 3.5절, 표 3 (E)

    일상으로 치면

    카드 더미를 섞어도 원래 순서를 되찾을 수 있게, 카드마다 빠른 박자부터 느린 박자까지 여러 물결의 높이를 도장으로 찍어 둔다. 가까운 카드끼리는 도장 모양이 비슷하다.

    모델에서는

    순환도 합성곱도 없으니 순서 정보를 따로 넣어야 한다. 단어 임베딩에 같은 크기의 위치 인코딩을 더한다. 차원마다 파장이 2π에서 10000·2π까지 기하급수로 늘어나는 사인·코사인이다.

    물결표 지도 실제 식 · d_model을 64로 줄여 그림

    기준 자리 pos10

    행동으로 보기 — 단어 순서를 뒤집으면 설명용 모형 · 실제 데이터 아님

    한 걸음씩

    1. 짝수 차원 2i에는 sin, 홀수 차원 2i+1에는 cos을 쓴다. 앞 차원은 빨리, 뒤 차원은 천천히 출렁인다.
    2. 어떤 고정된 간격 k에 대해 PE(pos+k)는 PE(pos)의 선형 함수로 쓸 수 있다. 논문은 그래서 "상대 위치로 어텐션하기 쉬울 것"이라 가정했다.
    3. 학습된 위치 임베딩으로 바꿔도 결과가 거의 같았다 (표 3 (E): BLEU 25.7 vs base 25.8). 그래도 사인 방식을 고른 이유는 학습 때보다 긴 문장에도 이어 쓸 수 있을지 모르기 때문이었다.

    이 칸의 한계: 모든 단어가 모든 단어를 보니 계산량이 문장 길이의 제곱(n²)으로 는다. 다음 칸에서 이 값과 얻는 것을 비교한다.

    초파리 연구원

    물결표를 끄면 두 문장 출력이 똑같네. 내 질문이 맞았던 거잖아. 그래서 붙인 거고.

    6결과 4

    왜 셀프 어텐션인가 — 그리고 번역 성적

    모델: 경로 길이 O(1), 순차 연산 O(1)일상: 회의에서 쪽지를 돌리기 vs 모두에게 바로 묻기논문: 표 1, 표 2

    일상으로 치면

    회의실 끝 사람에게 질문하려면, 쪽지를 옆 사람에게 차례로 건네면 n번 걸린다. 모두가 동시에 모두에게 물을 수 있으면 한 번이면 되지만, 대화 쌍이 사람 수의 제곱만큼 생긴다.

    모델에서는

    순환층은 n번 차례로 계산해야 하고 먼 단어 사이 경로도 n이다. 셀프 어텐션은 한 번에 계산되고 경로가 1이지만, 층마다 계산량이 n²·d다. 문장 길이 n이 표현 차원 d보다 작으면 순환층(n·d²)보다 오히려 싸다.

    행동으로 보기 — 쪽지 돌리기 도식 · 결과의 방향만 표현

    문장 길이 n12

    논문 수치 — 번역 점수와 학습 비용 논문 수치 · 표 2 (newstest2014)

    표 1 (원문 그대로) — n: 문장 길이, d: 표현 차원, k: 합성곱 폭, r: 제한 어텐션 이웃 크기
    층 종류층당 계산량순차 연산최대 경로 길이
    셀프 어텐션O(n²·d)O(1)O(1)
    순환O(n·d²)O(n)O(n)
    합성곱O(k·n·d²)O(1)O(logₖ(n))
    셀프 어텐션 (제한)O(r·n·d)O(1)O(n/r)

    표 2 읽을 때

    1. 영→독: big 28.4는 앙상블을 포함한 이전 최고(26.36)보다 2.0 넘게 높다. base 27.3도 이전 모든 모델·앙상블보다 높다.
    2. 학습 비용(FLOPs)은 저자들이 학습 시간 × GPU 수 × GPU 1장의 추정 성능으로 계산한 추정치다.
    3. 영→불 big 점수는 표 2와 초록에는 41.8, 6.1절 본문에는 41.0으로 적혀 있다. 이 페이지는 표 값을 쓰고 차이를 그대로 밝혀 둔다.

    이 칸의 한계: 아주 긴 입력(이미지, 음성, 긴 문서)에서는 n²가 부담이다. 논문은 이웃만 보는 제한 어텐션을 앞으로의 과제로 남겼다.

    생성 AI로 치면

    ChatGPT 같은 대형 언어 모델이 긴 대화의 앞부분을 참고하는 방식이 이 셀프 어텐션입니다. 한 번에 넣을 수 있는 길이(문맥 창)에 한도가 있는 이유 중 하나가 바로 n² 계산량입니다.

    비유의 한계: 오늘날 언어 모델은 대부분 쓰는 탑(디코더)만 쓰고, 크기·학습 방법·위치 표현이 이 논문과 다릅니다.

    박사

    세 가지를 같이 봐야 해요. 층당 계산량, 한꺼번에 돌릴 수 있는 정도, 먼 단어까지의 거리. 셀프 어텐션은 뒤의 둘에서 이기고, 첫째는 n이 d보다 작을 때 이깁니다.

    8다시

    다시 읽기 — 비유 카드와 한계

    형광펜 진하기일상 ↔ 어텐션 가중치

    질문과 잘 맞는 줄일수록 진하게.

    한계: 사람은 다시 읽을 줄을 고르지만, 모델은 모든 줄에 조금씩이라도 가중치를 준다.

    질문 카드·색인표·내용도서관 ↔ Q·K·V

    색인표로 맞는 책을 찾고 내용을 가져온다.

    한계: 하나만 고르지 않고 여러 책 내용을 비율대로 섞는다.

    색 다른 펜일상 ↔ 여러 머리

    색마다 다른 관계.

    한계: 머리의 "역할"은 미리 정하지 않는다. 학습 뒤에 해석하는 것이다.

    물결 도장일상 ↔ 위치 인코딩

    자리마다 다른 물결 모양을 더한다.

    한계: 도장을 "옆에 찍는" 게 아니라 단어 벡터에 "더한다".

    쪽지 돌리기 vs 모두에게 묻기회의 ↔ RNN vs 셀프 어텐션

    경로 n vs 경로 1.

    한계: 모두에게 묻기는 쌍의 수(n²)만큼 계산이 든다.

    앞만 보기 가림막받아쓰기 ↔ 디코더 마스킹

    아직 안 부른 단어는 못 본다.

    한계: 학습 때는 전체 정답 문장을 한꺼번에 넣고 가림막으로만 막는다.

    지름길보고서 결재 ↔ 잔차 연결

    원본을 첨부한 채 수정안을 올린다.

    한계: 원본과 수정안을 "더해서" 넘긴다.

    한 줄 식: 출력 = LayerNorm(x + Sublayer(x)), Sublayer ∈ { 여러 색 형광펜, 단어별 작은 신경망 }, 이것을 N = 6번 쌓는다.

    생성 AI로 치면

    "다음 단어를 하나씩 쓰고, 쓴 단어를 다시 입력으로 넣는" 쓰는 탑의 방식(자기회귀)이 오늘날 챗봇이 글을 한 토큰씩 만드는 방식과 같은 뼈대입니다. 파인튜닝·LoRA도 이 블록 안의 행렬을 조금 고치는 일입니다.

    비유의 한계: 이 논문 자체는 번역과 구문 분석만 실험했고, 대화형 AI를 다루지 않았습니다.

    현장에 옮기면

    번역 점수 표는 "같은 시험 세트, 같은 채점표" 위의 비교입니다. 사내 데이터에 쓸 때는 (1) 시험 세트를 먼저 봉인하고 (2) 기존 방식(기준선)과 같은 조건으로 비교하고 (3) 긴 입력에서 비용이 n²로 느는지 재 보세요.

    비유의 한계: BLEU가 높다고 현장 품질이 같은 비율로 좋아진다는 보장은 없습니다.

    9요약

    한 장으로

    순환은 순서대로라 느리다→형광펜(어텐션)만 쓴다→여러 색으로 관계를 나눈다→자리 물결표로 순서를 되살린다→더 높은 점수, 더 적은 학습 비용

    핵심 1

    트랜스포머는 순환·합성곱 없이 어텐션과 단어별 작은 신경망만으로 번역한다.

    핵심 2

    먼 단어 사이 경로가 1이고 문장 안 계산을 한꺼번에 돌릴 수 있어, 학습 비용이 크게 줄었다.

    핵심 3

    영→독 28.4, 영→불 41.8(표 2) BLEU로 당시 최고 기록을 냈고, 구문 분석에도 잘 옮겨졌다.

    읽을 때 주의할 점

    • 영→불 big 점수가 논문 안에서 41.8(초록·표 2)과 41.0(6.1절)으로 다르게 적혀 있다.
    • 표 3은 개발 세트(newstest2013), 표 2는 시험 세트(newstest2014). 두 표의 BLEU를 섞어 비교하지 않는다.
    • 머리가 문법을 "배운다"는 것은 저자의 해석이다. 논문은 "보이는 것 같다(appear to)"고 썼다.
    • 학습 비용은 저자의 추정치이며, 기존 모델 수치는 각 논문에서 가져온 것이다.

    모아의 기록장

    • 영→독 BLEU 28.4, 영→불 41.8 (표 2, 시험 세트 newstest2014)
    • 영→불 big 점수는 논문 안에서 41.8(초록·표 2)과 41.0(6.1절)으로 다르게 적혀 있음
    • 표 3은 개발 세트(newstest2013) — 표 2와 섞어 비교하지 않기
    • "머리가 문법을 배운다"는 저자의 해석
